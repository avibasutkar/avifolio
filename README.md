# 👨‍💻 Avinash Basutkar — Portfolio

🌐 A modern, responsive personal portfolio website built to showcase my professional profile, skills, projects, certifications, education, and experience.

## 🛠️ Tech Stack

- ⚛️ React
- 📘 TypeScript
- ⚡ Vite
- 🎨 Tailwind CSS
- ✨ Motion
- 🧩 Lucide React

## 🚀 Getting Started

### 📦 Install dependencies

```bash
npm install
```

### ▶️ Run the project

```bash
npm run dev
```

### 🏗️ Build the project

```bash
npm run build
```

### 👀 Preview production build

```bash
npm run preview
```
